VISORPDF3000 PRO - EDICION LIGERA (WINDOWS 10/11)
================================================

Esta version optimiza el EMPAQUETADO, sin quitar las funciones del proyecto
que proporcionaste: busqueda por contenido/nombre, OCR, vista previa,
paginas y zoom, favoritos, categorias, CSV y respaldo SQLite.

POR QUE ANTES PESABA TANTO
-------------------------
PyInstaller incluia librerias opcionales (PyTorch, SciPy, Pandas y mas).
Una DLL de PyTorch superaba 293 MB y GitHub rechazaba la subida.
El codigo original era muy pequeno; el exceso estaba en dist/build.

QUE CAMBIO
----------
- OCR usa directamente Tesseract.exe a traves de subprocess + PNG por stdin.
  Ya no necesita pytesseract ni Pillow para OCR.
- Requisitos: PySide6-Essentials, PyMuPDF y PyInstaller (solo compilacion).
- Se excluyen dependencias pesadas que el visor no utiliza.
- PyInstaller genera archivos temporales bajo %TEMP% en lugar de OneDrive.
- Deteccion PDF en una sola pasada, incluso extensiones .PDF.
- Nuevo .gitignore para excluir dist/, build/ y catalogos privados.
- El BAT respalda/restaura Data (catalogo, favoritos y configuracion) al actualizar.

COMPILAR PARA WINDOWS
---------------------
1. Descomprime este ZIP en una carpeta NORMAL (no ejecutes dentro del ZIP).
2. Abre VisorPDF3000Pro.
3. Haz doble clic en CREAR_PORTABLE.bat.
4. Si termina con COMPILACION COMPLETADA, abre:
   dist\VisorPDF3000Pro\VisorPDF3000Pro.exe
5. Para usar en otra computadora, copia toda la carpeta dist\VisorPDF3000Pro,
   nunca solo el archivo EXE.

SI YA TENIAS UN CATALOGO
------------------------
El BAT recupera los datos de dist\VisorPDF3000Pro\Data de una
compilacion anterior y deja una copia en Data_Respaldo_Compilacion.
Si tenias el catalogo en OTRA ubicacion, copia manualmente su carpeta
Data a la carpeta Data junto al EXE nuevo (con el visor cerrado).

OCR ESCANEADOS
--------------
El motor Tesseract sigue siendo externo y debe instalarse en cada PC
que necesite OCR de PDF escaneados.
https://github.com/UB-Mannheim/tesseract/wiki
Instala los paquetes de idioma spa y/o eng. Puedes elegir spa, eng o
spa+eng en el visor. Si Tesseract no se encuentra automaticamente,
configura en Data\config.txt la linea:
  tesseract=C:\Program Files\Tesseract-OCR\tesseract.exe
Los PDF con texto digital se indexan sin necesidad de Tesseract.

USO
---
1. Elige la carpeta que contiene tus PDF.
2. Pulsa Indexar / actualizar PDF (activa OCR si hay escaneos).
3. Escribe una palabra, frase, referencia o nombre y pulsa Buscar.
4. Selecciona un resultado para ver la pagina; usa zoom y navegacion.
5. Exporta resultados a CSV o crea una copia del catalogo cuando quieras.

GITHUB
------
El archivo .gitignore evita subir nuevas carpetas build/dist. Si ya
las agregaste en commits antiguos, .gitignore NO limpia el historial;
consulta GITHUB.txt antes de volver a ejecutar git push.

LIMITES DE LA ENTREGA
---------------------
Este ZIP contiene CODIGO FUENTE y archivos .bat. No incluye EXE compilado:
para obtenerlo se necesita ejecutar CREAR_PORTABLE.bat en Windows.
Tampoco incluye el ejecutable de Tesseract ni los idiomas instalados.
No se ha verificado el tamano final del EXE en Windows; depende de los
paquetes presentes y de la version del compilador.
